# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-22

### Added

- CLI modes: `scan`, `score`, `report`
- Schema inventory parser and RET-01…08 retention rules engine
- FAIL / PARTIAL / PASS banding with weighted scoring
- Markdown, JSON, and PDF exporters
- Sample CRM (FAIL) and HR (PASS) inventories with committed artefacts
- Docs: `STORAGE_LIMITATION_GUIDE.md`, README worked example, limitations
- GitHub Actions test pipeline (ruff, black, pytest coverage, bandit)
